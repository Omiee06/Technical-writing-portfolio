# 1. Introduction

## 1.1 About TaskFlow

TaskFlow is a web-based task management application that allows users to create, organize, and track tasks. Users can add task details, including titles, descriptions, due dates, and priorities.

## 1.2 Audience

This guide is intended for individual users and small team members who use TaskFlow to create, organize, and track tasks.

## 1.3 Key capabilities

- **Manage tasks:** Create tasks with titles, descriptions, due dates, and priorities; edit or delete existing tasks.
- **Track progress:** Update task status between **To Do**, **In Progress**, and **Completed.**
- **Find tasks:** Search for tasks by title.
- **Filter tasks:** Filter the task list by status.

## 1.4 Scope

This guide covers the core TaskFlow workflows for creating, editing, updating, and deleting tasks. It also covers the dashboard, task search by title, status-based filtering, and common troubleshooting issues.
