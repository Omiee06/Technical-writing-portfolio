# 1. Introduction

## 1.1 About TaskFlow

TaskFlow is a web-based task management application that allows users to create, organize, and track tasks. Users can add task details such as descriptions, due dates, and priorities, update task statuses, search for tasks by title, and filter tasks by status.

## 1.2 Audience

This guide is intended for individual users and small-team members who use TaskFlow to create, organize, and track tasks.

## 1.3 What You Can Do with TaskFlow

- **Manage tasks:** Create tasks with titles, descriptions, due dates, and priorities, and edit or delete existing tasks.
- **Track progress:** Update task statuses between **To Do**, **In Progress**, and **Completed**.
- **Find tasks:** Search for tasks by title.
- **Filter tasks:** Filter the task list by status.

## 1.4 Scope

This guide covers the core TaskFlow workflows for creating, editing, updating, and deleting tasks. It also covers the dashboard, task search by title, status-based filtering, and common troubleshooting scenarios.

This guide does not cover advanced administrative controls, third-party integrations, or filtering by due date or priority.

# 2. Getting Started

## 2.1 Access

Access TaskFlow through a web browser.

## 2.2 Dashboard Overview

The dashboard provides an overview of tasks, task statuses, filtering options, and upcoming due dates.

## 2.3 Common Task Workflow

A typical task workflow may include:

1. Create a task.
2. Edit task information when required.
3. Update the task status.
4. Search for or filter tasks.
5. Mark the task as completed when the work is finished.

## 2.4 Task Status

TaskFlow uses three statuses to track tasks:

1. **To Do**
2. **In Progress**
3. **Completed**

Users can update a task's status to reflect its current state and mark a task as completed when the work is finished.

# 4. Managing Tasks

## 4.1 Create a Task

**Purpose:**  
This feature allows users to create a task that can be organized and tracked in TaskFlow.

**Prerequisite:**  
No prerequisites are currently defined.

**Steps:**

1. Select **Create Task**.
2. Enter the task title.
3. Enter a description.
4. Set a due date.
5. Set the task priority.
6. Select **Create**.

**Expected result:**  
The task is created and can be viewed in TaskFlow with its due date.

---

## 4.2 Edit a Task

**Purpose:**  
This feature allows users to edit task information.

**Prerequisite:**  
The task must already exist.

**Steps:**

1. Open the task you want to modify.
2. Select **Edit**.
3. Update the task title, description, due date, or priority as needed.
4. Select **Save**.

**Expected result:**  
The updated task information is saved and the task can be viewed with the updated details.

**Note:**  
Any user who can view a task can edit it.

---

## 4.3 Update Task Status

**Purpose:**  
This feature allows users to update the status of a task.

**Prerequisite:**  
The task must already exist.

**Steps:**

1. Open the task you want to update.
2. Change the task status to **To Do**, **In Progress**, or **Completed**.
3. Select **Save**.

**Expected result:**  
The updated task status is saved and can be viewed in the task list.

**Note:**  
Users can move a task between **To Do**, **In Progress**, and **Completed** statuses, including moving a task back to an earlier status.

---

## 4.4 Delete a Task

**Purpose:**  
This feature allows users to delete a task.

**Prerequisite:**  
The task must already exist.

**Steps:**

1. Open the task you want to delete.
2. Select **Delete**.

**Expected result:**  
The task is deleted from TaskFlow.

**Note:**  
Deleted tasks cannot be restored.

---

# 5. Search and Filter

**Purpose:**  
This feature allows users to search for and filter tasks.

**Steps:**

1. Enter the task title in the search field.
2. Select the filter option and choose the required task status.

**Expected result:**  
The task list displays tasks that match the search or filter criteria.

**Notes:**

- Search accepts partial or complete task titles.
- Search is case-sensitive.
- Tasks can be filtered by status.
- Filtering by priority or due date is not supported.

# 6. Troubleshooting

## 6.1 Task Creation

### A task does not appear in the task list after creation

**Cause:**  
The task list has not been refreshed.

**Resolution:**  
Refresh the page.

**Expected result:**  
The newly created task appears in the task list.

### A task cannot be saved

**Causes:**

- The task title is missing.
- The task title exceeds 100 characters.
- The due date is earlier than the current date.

**Resolution:**  
Correct the missing or invalid information and save the task again.

**Expected result:**  
The task is saved.

---

## 6.2 Task Editing

### Changes to a task are not saved

**Cause:**  
The changes have not been saved.

**Resolution:**  
Select **Save** after making the required changes.

**Expected result:**  
The updated task information is saved.

---

## 6.3 Task Status

### The task status does not change

**Cause:**  
The status change has not been saved.

**Resolution:**  
Select **Save** after changing the task status.

**Expected result:**  
The updated task status is displayed in the task list.

---

## 6.4 Task Deletion

### A deleted task still appears in the task list

**Cause:**  
The page has not been refreshed.

**Resolution:**  
Refresh the page.

**Expected result:**  
The deleted task no longer appears in the task list.

**Note:**  
Deleted tasks cannot be restored.

---

## 6.5 Search

### Search does not return results for a matching task

**Cause:**  
The search is case-sensitive.

**Resolution:**  
Enter the task title using the correct capitalization.

**Note:**  
Search accepts partial or complete task titles.

---

## 6.6 Filtering

### The selected filter does not work

**Cause:**  
The selected status filter has not been applied.

**Resolution:**  
Select the required status and apply the filter.

**Note:**  
Users can filter tasks by status, but not by priority or due date.
